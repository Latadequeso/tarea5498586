GAMEVAULT - Biblioteca virtual de videojuegos

Ejecuta index.html con Live Server o desde tu navegador.

Estructura:
- index.html: estructura semántica HTML5.
- css/styles.css: estilos, Grid, Flexbox y Media Queries.
- js/app.js: catálogo, favoritos, formulario y almacenamiento local.
- img/: portadas JPG de muestra.
- Documentacion_GameVault.pdf: documentación del proyecto.

El formulario acepta portadas JPG/JPEG. Los cambios se guardan en localStorage del mismo navegador y dispositivo; no existe sincronización en la nube.
